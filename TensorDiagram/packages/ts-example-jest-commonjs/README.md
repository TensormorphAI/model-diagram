# Integrate `TensorDiagram` in CommonJS Jest tests with ts-jest

Demonstrate how to run jest tests involving `TensorDiagram` with ts-jest, using CommonJS.

`jest-jsdom` is required as `TensorDiagram` depends on browser objects.

## Setup

Initialize all packages
> From the repository root, run `npm install`.
 
Build tensordiagram@core
> From the `packages/core` directory, run `npm run build`.
